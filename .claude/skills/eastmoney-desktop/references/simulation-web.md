# 东方财富官方模拟盘

用于用户明确要求在东方财富模拟账户中测试提交、买卖或撤单的任务。桌面证券账户仍维持不提交委托的边界。

## 入口与账户

2026-10-16检查的官方入口：

- [创建模拟组合](https://group.eastmoney.com/createcom.html)：页面将组合定义为模拟资金账户，并列出对外隐藏选项。
- [模拟交易室](https://group.eastmoney.com/room/index.html)：提供买入、卖出、挂单、持仓、当日委托、当日成交和资金流水。

网站账户和Windows证券交易客户端的认证相互独立。人工在网页中完成登录，不读取密码、短信或其他应用中的认证信息。用户已有多个组合时明确选择目标；新建测试组合使用清楚的测试名称并设为仅自己可见，不能改变现有组合或公开用户信息。

## 执行及证据

先核对当前页面的主机严格为 `group.eastmoney.com`、路径为已检查的模拟交易页面，再核对模拟组合标识、名称、虚拟资金、已有持仓和未结委托。网站导航含实盘证券交易链接，不进入这些链接。重定向、未知弹窗、组合选择不明确时停止。

先记录余额、持仓及委托；选择模拟盘支持的标的及明确参考价，使用最小测试数量。提交前回读方向、代码、价格、数量及目标组合。一次提交后查询委托编号和状态，再查询成交与资金变化；超时和回报未知时先查单，不能盲目重发。

买入、卖出、未成交订单撤单分别记录结果。卖出限已有可卖数量；没有可卖持仓或模拟盘限制当日卖出时，如实记录限制，不伪造持仓和成交。只撤本次创建且编号明确的测试委托；撤单请求成功不等于最终撤成，需查询最终回报。

浏览器截图、订单编号、资金和账户信息仅放在Git忽略的 `data/eastmoney/official-simulation/`。每项区分已提交、已受理、已成交、已撤、拒绝和结果未知。自动化框架或页面可打开不能记为模拟交易通过。
