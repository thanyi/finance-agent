# analyze-stock

> 数据接入：先运行 `stock-data-collect`，逐项读取 `report.json` 指标的 `value/status/source/asof`；`partial` 不代表完整采集。人工从原始公告补到的证据单独注明链接和页码，不伪装成接口返回。2024-08-19后公开北向买卖额披露调整，近10/20日净流入默认标注缺失；缺失不得视为任何信号满足。

对指定A股标的执行完整的M1-M6价值投资深度分析。

## 使用方式

```
/analyze-stock [股票代码]
示例：/analyze-stock 002415（海康威视）
```

---

## 执行流程（SOP）

```
Step 1  调用 /stock-data-collect [股票代码]，完成数据采集
         ↓
Step 2  数据质量核查（异常值标注⚠️，缺失项标注[数据缺失：原因]）
         ↓
Step 3  M1-M6 六模块分析（严格按各模块框架执行）
         ↓
Step 4  输出各模块结论（含评级⭐，含数据来源）
         ↓
Step 5  汇总综合结论（按本文输出模板）
         ↓
Step 6  数据纪律自查（无编造，无估算，无缺失未标注）

⚠️ 每一步若数据无法获取，先标注原因，再分析有证据支持的部分；关键证据不足的模块写“未评级”。
```

## M1｜经济护城河分析（20%）

> 哲学来源：巴菲特"护城河"概念——决定企业能否长期维持超额利润。

**1.1 护城河类型识别**（逐一验证，必须用数据支撑：有 / 弱 / 无）

| 护城河类型 | 验证指标 | 数据要求 |
|---|---|---|
| 品牌溢价 | 毛利率高于行业均值 | 毛利率数据 |
| 网络效应 | 用户增长与价值正反馈 | 用户数据（若有披露）|
| 成本优势 | 单位成本低于同行 | 同行对比数据 |
| 转换成本 | 客户流失率、续约率 | 年报披露 |
| 规模效应 | 市占率 & 固定成本摊薄 | 行业市占率 |
| 无形资产 | 专利数、特许经营权 | 年报披露 |
| 政策壁垒 | 牌照稀缺性 | 监管文件 |

**1.2 护城河宽度评估**
- 近5年ROE（扣非）稳定性：稳定高于15%是强护城河信号
- 毛利率趋势：扩张 / 收窄 / 承压
- 市场份额变化：扩大 / 稳定 / 流失

**1.3 护城河威胁**
- 技术颠覆风险
- 政策收紧风险（A股特有：行业监管骤变）
- 外资/跨界竞争者进入

```

护城河类型：[填写]
宽度判断：[宽/窄/无]，依据：[数据]
主要威胁：[填写]
数据来源：[填写]
```

## M2｜财务健康度 & 盈利质量分析（25%）

> 哲学来源：格雷厄姆《证券分析》严格财务标准 + A股财务造假识别体系

**2.1 核心财务指标（核查近5年趋势；缺失项须注明原因）**

盈利能力：

| 指标 | 计算方式 | 参考判读（须结合行业） |
|---|---|---|
| 扣非ROE | 以公司披露的扣非加权ROE为准，不用简单平均净资产冒充 | >15% 优秀，连续5年>12%为强质地 |
| 毛利率 | 毛利润 / 营收 | 行业对比，重点看趋势 |
| 净利率 | 扣非净利润 / 营收 | >10% 优选 |
| ROA | 净利润 / 平均总资产 | >6% 健康 |

偿债能力：

| 指标 | 计算方式 | 警戒线 |
|---|---|---|
| 资产负债率 | 总负债 / 总资产 | >70% 高风险（制造业）；金融业单独评估 |
| 有息负债率 | 有息负债 / 总资产 | >40% 警惕 |
| 流动比率 | 流动资产 / 流动负债 | <1.0 危险 |
| 利息保障倍数 | EBIT / 利息支出 | <3倍 警惕 |

现金流质量：

| 指标 | 说明 | 健康标准 |
|---|---|---|
| FCF（自由现金流）| 经营CFO - 资本支出 | 连续5年为正 |
| 净利润现金含量 | 同期合并经营CFO / 合并净利润 | >80% 健康，<60% 警惕；半年数据还须对照上年同期与完整年报 |
| 应收账款增速 vs 营收增速 | 两者分别按可比基期计算，注明期末或同比口径 | 持续高于营收时需核查回款，不据单期断定异常 |

运营效率：应收账款周转天数 / 存货周转天数 / 总资产周转率（均需对比行业均值）

**2.2 A股财务异常线索**（逐项核查；触发线索不等于认定造假）

```
□ 营收高增长但经营现金流持续为负或远低于净利润
□ 应收账款增速连续3年高于营收增速30%以上
□ 存货大幅增加但营收未同步增长
□ 在建工程长期挂账（超过行业建设周期）
□ 货币资金大量但同时大量有息借款（矛盾资金结构）
□ 关联方应收款占总应收比例超过30%
□ 审计意见非标（须⚠️⚠️标注）
□ 频繁更换审计机构（3年内更换2次以上）
□ 商誉占净资产比例超过50%（并购泡沫风险）
□ 毛利率显著高于同行但无合理解释
□ 净利润连续多年呈现"整数"或过于平滑
□ 控股股东股权质押比例超过60%
□ 实控人存在非经营性占款记录
□ 子公司众多且分布于注册地隐蔽地区（如BVI离岸公司）
```

Beneish 指标逐项核查（有数据时执行）：

```
DSRI = (应收/营收)_t / (应收/营收)_t-1
GMI  = 毛利率_t-1 / 毛利率_t
AQI  = (1-(流动资产+固定资产)/总资产)_t / (1-(流动资产+固定资产)/总资产)_t-1
SGI  = 营收_t / 营收_t-1
DEPI = 折旧率_t-1 / 折旧率_t
以上只是部分指标。未采齐完整模型所需变量、未核对财报口径时，不得计算或引用 Beneish M-Score 及其阈值。
```

**2.3 扣非ROE vs 可比同行**：优先选至少3家业务相近的公司、同一完整年报期及同一指标口径；业务结构差异大时逐家列示，不把算术均值称为行业基准。

```
【M2 财务健康度】评级：⭐⭐⭐
财务异常线索：[列明事实、期间与待核问题；不得仅凭信号推断造假]
⚠️ 异常数据：[列举]
扣非ROE趋势：[逐年披露值]；同行对照：[可比公司、年度及结构差异，若无则标注缺失]
FCF状况：连续5年正/部分年度负/持续为负
现金流质量：健康/警惕/异常
数据来源：[列举接口]
```

## M3｜商业模式 & 管理层分析（15%）

> 哲学来源：费雪《怎样选择成长股》"15要点"中对管理层的重视

**3.1 商业模式**
- 收入结构：主营业务清晰度，单一来源风险 vs 多元化
- 定价权：能否主动提价？客户对提价的接受度（费雪核心看点）
- 客户集中度：前5大客户占营收比例（>50%需⚠️）
- 供应商集中度：前5大供应商占采购比例（>70%需⚠️）
- 商业模式可复制性：竞争者进入门槛

**3.2 管理层量化指标**

| 维度 | 数据来源 | 说明 |
|---|---|---|
| 管理层薪酬/净利润比率 | 年报 | 过高需⚠️ |
| 实控人/大股东增减持记录 | 交易所公告 | 大幅减持需⚠️ |
| 股权质押比例 | 巨潮资讯 | >60%需⚠️⚠️ |
| 高管离职频率 | 公告 | 核心管理层频繁离职需⚠️ |
| 股权激励计划 | 公告 | 考核指标是否合理 |
| 分红稳定性 | 分红历史 | 连续10年分红是正信号 |

年报披露的董高薪酬合计可能包含已离任人员，计算薪酬/利润比例时说明范围；核对持股是否为直接持股，不能与控股股东持股混同。客户、供应商集中度优先取年报原文并记录页码。

**3.3 定性评估**（基于公开信息）
- 战略一致性：近5年战略是否清晰、未频繁转向
- 资本配置能力：ROE vs 同期再投资回报率
- 股东回报意识：股息率、回购历史
- 历史承诺兑现率：对比过往业绩指引与实际结果

## M4｜增长天花板 & 驱动力分析（15%）

> 哲学来源：费雪成长股投资理论——寻找长期成长的驱动力

**4.1 行业空间分析**
- 行业生命周期：导入期 / 成长期 / 成熟期 / 衰退期（必须注明依据）
- 行业规模与增速：当前市场规模（必须引用官方/权威来源）
- 渗透率空间：目标公司当前渗透率 vs 可能上限
- 政策催化剂：近2年重大行业政策（来源：国务院、发改委、监管部门）

**4.2 成长驱动力**（无数据支撑的不得写入）

```
□ 市场份额扩张（数据：市占率变化）
□ 产品/服务提价能力（数据：ASP历史变化）
□ 新产品线渗透（数据：各产品线营收贡献）
□ 地理扩张（数据：区域营收变化）
□ 并购整合（数据：并购标的ROI）
```

**4.3 天花板评估**
- 仅当公司营收与行业规模覆盖相同产品、地区和期间时，才用两者之比估算市占率
- 市占率已超40%，增长空间显著收窄，需标注
- 海外扩张可能性（若有，需评估汇率风险和地缘政治风险）
- 在手订单注明统计截止日、业务范围与收入确认条件；先判断“其中”是否为总额的子集，不能直接相加或当作未来利润。产品出货增速不能代替整个业务收入增速。

**4.4 A股特有政策风险**

```
□ 是否处于政策强监管行业（教育/游戏/医疗/地产/金融）
□ 是否依赖政府补贴（补贴占利润比例 > 20%需⚠️）
□ 是否存在"运动式"政策风险（如双碳、反垄断等）
□ 是否存在地方政府关系高度绑定风险
```

## M5｜市场情绪 & 筹码结构分析（10%）

> 市场情绪可使价格短期偏离基本面；涉及投资者结构的比例须查证当期数据。
> **情绪是辅助工具，不是决策依据。**

**5.1 筹码结构评估维度**

| 维度 | 含义 | 判断标准 |
|---|---|---|
| 股东人数变化趋势 | 账户分布变化 | 以报告期末日期比较；变化不能识别买卖方身份 |
| 机构持仓比例 | 聪明钱认可度 | <5%或持续下降需⚠️ |
| 融资余额/流通市值 | 杠杆情绪 | >5%说明情绪偏热 |
| 北向资金净流向 | 外资动向参考 | 近10/20日净流入不可可靠取得时标注缺失，不用香港中央结算持股变动代替 |

**5.2 价格与情绪分析**
- 52周价格区间：当前股价处于低位/中位/高位
- 换手率：>10%单日往往是情绪峰值信号
- A股散户特征：追涨杀跌 / 概念炒作 / 政策市 / 年报季信息差

**5.3 情绪极致谨慎原则**

```
【禁止基于情绪做正面判断的情境】
- 股价30个交易日内涨幅超过50%（无论基本面如何）
- 社交媒体出现大规模"百倍股"讨论
- 行业出现"风口"概念集体炒作
- 公司连续涨停（定性：投机行为，非价值发现）

【可信的反向情绪信号（必须配合基本面使用）】
- 股东人数连续增加但股价横盘/下跌（筹码分散，需结合持有人结构核查）
- 机构持续减持（smart money离场信号）
- 融资余额快速上升（杠杆情绪峰值）
```

```
【M5 市场情绪 & 筹码结构】评级：⭐⭐⭐
情绪状态：恐慌/低迷/正常/偏热/狂热
筹码结构：集中/分散/持续集中中/持续分散中
⚠️ 情绪风险提示：[列举]
当前时机判断：低估逆向布局窗口/合理区间/情绪溢价过高
数据来源：[列举]
```

## M6｜估值 & 安全边际分析（15%）

> 哲学来源：格雷厄姆《聪明的投资者》——安全边际是投资的核心原则

**6.1 多维估值**

DCF（自由现金流折现）：

```
⚠️ DCF对假设极度敏感，必须做敏感性分析，禁止单一DCF结论作为买入依据

输入参数（均需基于历史数据，禁止主观假设过于乐观）：
- FCF历史均值（5年）：取实际数据
- 成长率：仅在期初和期末 FCF 均为正且口径一致时计算 CAGR；FCF 非正或波动剧烈时不套用 CAGR
- 折现率：说明资本成本、债务成本与资本结构的来源，并做敏感性分析；不使用统一固定值
- 永续增长率：不超过3%（GDP增速参考）

输出：悲观 / 中性 / 乐观三种假设下的内在价值
```

相对估值：

| 估值指标 | 最近已核验交易日数值 | 同口径5年分位/中位数 | 可比同行同日值 | 结论 |
|---|---|---|---|---|
| PE（TTM）| [数据] | [数据] | [数据] | 高/合理/低估 |
| PB | [数据] | [数据] | [数据] | 高/合理/低估 |
| PS | [数据] | [数据] | [数据] | 参考 |
| EV/EBITDA | [数据] | [数据] | [数据] | 参考 |

**6.2 安全边际**

```
安全边际 = (内在价值 - 当前股价) / 内在价值 × 100%

> 30%  → 较充足安全边际（格雷厄姆标准：不低于33%）
15-30% → 安全边际有限，需对质地更有把握
< 15%  → 安全边际不足，不符合价值投资买入标准
< 0%   → 当前价格高于内在价值，高估
```

□ 小盘股流动性折价：酌情调整
