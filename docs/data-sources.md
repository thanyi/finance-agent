# 数据采集接口审查与使用约定

审查日期：2026-09-29。采集代码在 `scripts/collect_finance.py`，接口隔离与降级在 `scripts/data_sources.py`，计算在 `scripts/finance_metrics.py`。本次保留工作区已有修改；`examples.py` 是依赖其他项目模块的参考代码，不作为可运行入口，也未直接接入生产采集。

## 审查发现与修正

| 原问题 | 本次处理 |
|---|---|
| 财务比率表被用于“完整报表”流程，缺少CFO/资本支出原始金额 | 东财三张合并财报→新浪；原表完整落盘，标准化关键金额，同期计算FCF，缺失不补零 |
| 股票当前PE/PB长期留空 | BaoStock日线PE(TTM)/PB(MRQ)；缺字段时降级百度带日期估值 |
| BaoStock已返回PS，但报告漏掉PS及股票估值历史分位 | 接入PS(TTM)与PE/PB/PS同源5年经验分位；无5年有效样本时明确缺失，不以近一年序列冒充 |
| 应收、存货和借款只能在庞大原表中查找 | 在标准化资产负债表新增应收、存货、流动资产/负债和主要债务分项，仍保留原表核验 |
| 财务与行情逻辑散落代码块，前块失败可能导致后块变量未定义 | 三类标的统一CLI，逐接口隔离，独立输出缺失状态 |
| 固定2020年起始日期、未来季度无效查询、未保留统一证据 | 动态近6年窗口；年报/累计季度区分；原表、参数、时间、库版本、失败记录落盘 |
| 中证接口有OHLC列但数据可能为空 | OHLC逐项校验；指数行情用BaoStock→东财→新浪，中证仅采估值证据 |
| 深证指数错误路由到中证估值 | 显式指数映射；深证估值可选Tushare，未启用时说明缺失 |
| 单日北向快照被当成10日历史 | 删除该逻辑；披露调整后不以成交总额/额度倒推净流入 |
| RSRS边界及恒定低价窗口不稳定 | 18日回归+600斜率，最少617个交易日；零方差不输出数值 |
| 换手率全零阻止成交额降级 | 全零视为不可用，尝试成交额代理并记录方法 |
| ETF只有分析清单，无采集程序 | 添加价格、净值、档案、费用、份额、持仓采集；同日收盘溢价、成交额、披露期AUM及费率提取 |
| 新闻无密钥崩溃、时区日期异常、窗口放宽到2倍、正文无链接 | 显式未配置状态、东方财富备用、UTC日期处理、严格时间窗、保留来源URL |
| 新闻代码含硬编码API密钥 | 改为环境变量，日志脱敏；原密钥应在服务商后台撤销/轮换 |

## 数据源取舍

默认走无需密钥的可验证数据源；AKShare只是适配器，多条AKShare接口指向同一网站时不算独立交叉验证。官方公告、交易所和基金公司披露是冲突核验依据。

- **公司报表**：东财三张合并报表包含原始项目，新浪作备用与独立核验。财务比率不能替代原始报表。接口与输入格式见 [AKShare股票文档](https://akshare.akfamily.xyz/data/stock/stock.html)。
- **行情与指数估值**：完整OHLC优先BaoStock，东财/新浪补充；中证历史滚动PE与近期市盈率1单独使用，不跨口径拼接。中证成交金额原单位为亿元，不能直接与元相加。[AKShare指数文档](https://akshare.akfamily.xyz/data/index/index.html)
- **股票PS及EV/EBITDA**：PS(TTM)直接取BaoStock日线；百度当前适配器只支持PE/PB备用，不把不存在的PS字段硬接进去。EV/EBITDA需要同日市值、现金及完整有息债务和TTM EBITDA，目前不自动计算或用净利润代替。[AKShare股票文档](https://akshare.akfamily.xyz/data/stock/stock.html)
- **ETF**：东财价格与净值、天天基金档案和费率，同花顺基本信息；交易所份额用于同日规模核验。累计净值与分红再投资净值不同。[AKShare基金文档](https://akshare.akfamily.xyz/data/fund/fund_public.html)
- **Tushare是显式可选扩展**：设置 `TUSHARE_TOKEN` 并传 `--tushare`，不自动购买权限。`index_dailybasic` 文档说明有积分要求、3000条单次上限和有限指数覆盖；当前6年窗口低于该上限。PE/PB为社区计算口径，不与中证混为同一序列。[官方接口说明](https://tushare.pro/document/2?doc_id=128)
- **北向净流入**：港交所公告说明日/月买卖额的披露调整，剩余调整于2024-08-19生效。日成交总额仍不等于净买入，因此默认返回明确缺失。[披露项目](https://www.hkex.com.hk/-/media/HKEX-Market/Services/Circulars-and-Notices/Participant-and-Members-Circulars/SEHK/2024/CT03824E.pdf)、[实施日期](https://www.hkex.com.hk/-/media/HKEX-Market/Services/Circulars-and-Notices/Participant-and-Members-Circulars/HKSCC/2024/ce_HKSCC_NOM_217_2024.pdf)
- **新闻**：Tavily只在配置环境密钥时启用；新闻查询指定 `topic=news` 和时间窗，失败或无配置时按股票代码查东财新闻。没有可靠发布日期的结果明确标为待核验，不能用于时效性事实判断。[Tavily参数文档](https://docs.tavily.com/documentation/api-reference/endpoint/search)

## 输出契约

每次创建独立目录。原始响应表保存在 `*_raw.csv`，标准化表在 `<数据集>.csv`；关键派生指标在 `report.json`。CSV不是原始HTTP报文，但保留接口返回的全部列与记录。失败接口在 `datasets.<名称>.attempts` 中记录平台、接口、参数、查询时间与原因。

`metrics.<名称>` 包含 `value/status/source/asof/unit`，必要时包含 `method/verification/reason`。JSON中的缺失用 `null`，不输出NaN/Infinity。`datasets.status=ok` 表示接口返回并通过该表配置的校验，不承诺所有原始列均完整；附加资料仍须核对。`report.status=partial` 表示有缺失项，脚本正常退出以便下游使用部分证据，绝不意味着分析依据完整。

采集请求截止日期为上海时区昨日，避免使用未收盘日线。行情/估值14自然日的新鲜度检查是粗筛，尚未接入完整交易日历；必须展示真实数据日期，停牌、假期和更新延迟仍需核对。股票财报是查询时的修订版本，不是历史时点数据库。原始附加表不自动抹去修订记录。

`reported_aum` 是最近披露期规模，`aum` 是有同日份额及净值证据时的计算规模；不可相互冒称实时值。管理费与托管费仅按基金档案字段提取，生效日须查基金公司公告。

## 验证与已知限制

在本机隔离环境安装 AKShare 1.18.88、BaoStock 0.9.4 后实际查询：

| 样本 | 联网结果 |
|---|---|
| 股票600519 | 三张报表各24个近6年报告期；东财/新浪同期核验成功；1454条日线；指标、分红、股东、主营和440条公告索引有返回 |
| 沪深300（000300） | 1454条日线、1454条中证估值记录、国债数据有返回；成功计算趋势及有足够覆盖的PE分位 |
| 创业板指（399006） | 行情与国债成功；未配置授权估值源时PE/PB明确缺失，不误调中证接口 |
| ETF510300 | 行情、净值、同花顺档案、天天基金费用/规模及两年持仓有返回；雪球档案接口报错；上交所份额首次SSL失败，最终复测成功并计算同日AUM（接口存在间歇故障） |
| 新闻600519 | 不使用Tavily密钥时，东财备用源成功返回近7日新闻 |

联网成功仅说明上述样本在本次环境下可用，不保证其他代码、未来时间或全部历史字段。Tushare无已验证授权，已测试适配/缺密钥路径和同源计算逻辑，但未声称完成其付费权限联网验证。

运行 `python -m pytest -q`：回归测试覆盖失败降级、总时限、空表/变更字段、过期行情、重复日期、缺失现金流项目、股票PS与关键资产负债表字段、单位、分位覆盖、RSRS、ETF日期对齐、Tushare口径和新闻时区。6个skill通过frontmatter校验。

本机默认Python 3.9链接LibreSSL，urllib3发出兼容性警告；推荐使用Python 3.11+与OpenSSL环境。没有关闭TLS证书验证，也没有全局删除代理。

仍需人工/授权数据补充：原始年报页码及审计事项、管理层薪酬/持股、同行口径选择、部分指数PB、ETF完整6月规模历史、官方TE/TD与申赎状态。缺少这些证据时仅输出局部分析和明确缺失，不宣称“全量覆盖”。
